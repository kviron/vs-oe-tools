# 🧪 Пошаговая инструкция тестирования LogCChangedObject

## 📋 Требования перед тестированием

- ✅ Установлено расширение VC-VE-Tools
- ✅ Настроено подключение к БД (Vars.bat)
- ✅ Доступ к таблицам: Methods, Abstract, LogCChangedObject
- ✅ PowerShell или CMD для установки переменной окружения

---

## 🔧 Шаг 1: Подготовка окружения

### 1.1. Получить реальный UserID из БД

Выполните в SQL Monitor расширения (Alt+Shift+I) или через SQL-клиент:

```sql
-- Получить ID пользователя (может быть разным в вашей БД)
SELECT ID, UserName, LoginName FROM Users LIMIT 10;

-- Или найти конкретного пользователя
SELECT ID FROM Users WHERE UserName = 'ваше_имя';
```

Запомните или скопируйте значение ID (в примере: 3130673).

### 1.2. Установить переменную окружения

**Вариант 1: PowerShell (Windows)**
```powershell
# Откройте PowerShell
$env:VC_VE_USER_ID = "3130673"

# Проверьте, что переменная установлена
$env:VC_VE_USER_ID
# Должно вывести: 3130673

# Теперь запустите VS Code из этого же PowerShell
code
```

**Вариант 2: CMD (Windows)**
```cmd
# Откройте CMD
set VC_VE_USER_ID=3130673

# Проверьте
echo %VC_VE_USER_ID%
# Должно вывести: 3130673

# Запустите VS Code
code
```

**Вариант 3: bash/zsh (Linux/macOS)**
```bash
export VC_VE_USER_ID=3130673
code
```

### 1.3. Открыть расширение

В VS Code:
1. Откройте папку проекта (если еще не открыта)
2. На левой панели нажмите на иконку "Восточный Экспресс"
3. Разверните "Проводник"
4. Должны видны классы и методы

---

## 📝 Шаг 2: Выбрать метод для редактирования

### 2.1. Найти метод

1. В Проводнике разверните класс
2. Выберите любой метод с кодом
3. Запомните ID метода (видно в скобках)

Пример: `Метод1 (41657448)` - ID = 41657448

### 2.2. Открыть метод в редакторе

1. Дважды щелкните на методе
2. Откроется табулятор с кодом (расширение .pas или .pkf)
3. Код загружается из БД в декодировке Windows-1251

---

## ✏️ Шаг 3: Редактировать код

### 3.1. Вариант 1: Простое изменение (добавить комментарий)

```pascal
procedure (Sender: wPersistent);
begin
  // Тестовое изменение - 2026-09-02 13:00
  
end;
```

### 3.2. Вариант 2: Изменить логику

```pascal
procedure (Sender: wPersistent);
begin
  // Добавляем новую строку
  DoSomething();
end;
```

### 3.3. Вариант 3: Добавить кавычки и специальные символы

```pascal
procedure (Sender: wPersistent);
begin
  ShowMessage("Тестовое сообщение");
  // Кавычки будут экранированы как ""
end;
```

**Не сохраняйте пока!**

## 💾 Шаг 4: Проверить, что код изменился

1. Заголовок вкладки должен содержать белую точку (несохраненные изменения)
2. Строка состояния показывает "Редактировано"

---

## 💿 Шаг 5: Сохранить изменения

### 5.1. Нажать Ctrl+S

1. Нажмите **Ctrl+S** в редакторе
2. Статус-бар должен показать: "Метод XXX сохранён в Windows-1251"
3. Белая точка исчезает (изменения сохранены)

### 5.2. Проверить отсутствие ошибок

1. Если видна ошибка в консоли (F12), значит что-то не так
2. Проверьте переменную окружения VC_VE_USER_ID

---

## 🔍 Шаг 6: Проверить LogCChangedObject

### 6.1. Открыть SQL Monitor расширения

1. Нажмите **Alt+Shift+I** (или используйте панель "Исполнитель SQL")
2. Откроется вкладка SQL в нижней части экрана

### 6.2. Выполнить SQL запрос

Замените `<METHOD_ID>` на ID метода из Шага 2.1:

```sql
SELECT 
  ObjID as "Method ID",
  UserID,
  ComputerName,
  ChangeDate,
  LENGTH(NewValues) as "NewValues Length",
  SUBSTR(NewValues, 1, 80) as "NewValues Preview"
FROM LogCChangedObject
WHERE ObjID = <METHOD_ID>
ORDER BY ChangeDate DESC
LIMIT 1;
```

Пример с ID = 41657448:
```sql
SELECT 
  ObjID as "Method ID",
  UserID,
  ComputerName,
  ChangeDate,
  LENGTH(NewValues) as "NewValues Length",
  SUBSTR(NewValues, 1, 80) as "NewValues Preview"
FROM LogCChangedObject
WHERE ObjID = 41657448
ORDER BY ChangeDate DESC
LIMIT 1;
```

### 6.3. Проверить результаты

Должны видны:
- ✅ **ObjID** = ID вашего метода (41657448)
- ✅ **UserID** = 3130673 (или установленное значение)
- ✅ **ComputerName** = имя вашего компьютера (например, OE-070)
- ✅ **ChangeDate** = дата/время ближайшая к текущей
- ✅ **NewValues Length** > 0 (содержит сериализованные значения)
- ✅ **NewValues Preview** начинается с `127,"`

## 📖 Шаг 7: Сравнить старый и новый код

### 7.1. Выполнить SQL запрос для детального просмотра

```sql
SELECT 
  ObjID,
  OldValues,
  NewValues,
  ChangeDate,
  UserID
FROM LogCChangedObject
WHERE ObjID = <METHOD_ID>
ORDER BY ChangeDate DESC
LIMIT 2;
```

### 7.2. Проверить формат

Должны видны строки вида:
```
NewValues: 127,"procedure (Sender: wPersistent);
begin
  // Комментарий
end;
",102,10824991

OldValues: 127,"procedure (Sender: wPersistent);
begin

end;
",102,10824991
```

**Различия:**
- В NewValues добавлен комментарий `// Комментарий`
- Кавычки экранированы как `""`
- Переводы строк сохранены

---

## 🔄 Шаг 8: Проверить, что Синхронизация пакетов видит изменения

### 8.1. Открыть Проводник расширения

1. На левой панели найдите "Синхронизация пакетов"
2. Если её нет, раскройте раздел "Восточный Экспресс"

### 8.2. Найти класс метода

1. В Проводнике найдите класс, к которому принадлежит метод
2. Класс должен быть помечен как "Измененный"
3. Разверните класс
4. Должны видны изменения методов в дереве

### 8.3. Проверить атрибут RootObjID

Выполнить SQL для проверки:
```sql
SELECT 
  ObjID as "Method ID",
  RootObjID as "Class ID",
  a.Name as "Class Name"
FROM LogCChangedObject lc
LEFT JOIN Abstract a ON a.ID = lc.RootObjID
WHERE lc.ObjID = <METHOD_ID>
ORDER BY lc.ChangeDate DESC
LIMIT 1;
```

## ❌ Тест 9: Проверить, что код БЕЗ ИЗМЕНЕНИЙ не логируется

### 9.1. Открыть тот же метод снова

1. Дважды щелкните на методе (если закрыли)
2. Или переключитесь на вкладку, если была открыта

### 9.2. НЕ менять код

1. Просто нажмите Ctrl+S БЕЗ изменений
2. Статус-бар должен показать "Метод XXX сохранён в Windows-1251"

### 9.3. Проверить, что LogCChangedObject НЕ пополнился

```sql
SELECT COUNT(*) as "Total Changes"
FROM LogCChangedObject
WHERE ObjID = <METHOD_ID>
  AND ChangeDate > NOW() - INTERVAL '1 minute';
```

**Ожидаемо:** Результат = 0 или то же число, что было раньше (без увеличения)

## 📊 Итоговая проверка через SQL

### Выполнить полный отчет по всем изменениям метода:

```sql
SELECT
  ROW_NUMBER() OVER (ORDER BY ChangeDate ASC) as "Ver",
  ChangeDate,
  UserID,
  ComputerName,
  ObjClassID,
  ChangeType,
  RootObjClassID
FROM LogCChangedObject
WHERE ObjID = <METHOD_ID>
ORDER BY ChangeDate ASC;
```

**Ожидается:**
- Несколько строк (по числу сохранений)
- Все поля заполнены корректно
- ObjClassID = 5 (объект метода)
- ChangeType = 2 (изменение)
- RootObjClassID = 3 (класс)
