# Карты взаимосвязей в расширении

Редактор собирается Vite и поставляется внутри VSIX. При работе расширения отдельный Vite/HTTP-сервер и дополнительный MCP не нужны. Команда «Восточный Экспресс: Открыть карту взаимосвязей» открывает отдельную Webview-панель.

Существующий MCP vc-ve-tools предоставляет list_maps, read_map, save_map, get_map_changes и open_map. Эти инструменты используют авторизованный мост работающего Extension Host. После установки новой сборки перезагрузите окно VS Code и переподключите MCP, чтобы агент получил новый каталог инструментов.

Карты хранятся в .vscode/relationship-maps первого рабочего каталога. Без открытого каталога используется глобальное хранилище расширения. Исходная карта extension копируется из ресурсов только при отсутствии сохранённой карты.

Новая карта: save_map с name, map и expectedRevision: null, затем open_map с тем же name. Минимальный map: { "schemaVersion": 2, "title": "Моя карта", "nodes": [], "edges": [] }. Узел содержит id, kind, title, x, y; связь — from, to, type. Поддерживаются описания, entityRef, attributes, sourceRefs, локальные nodeKinds/edgeKinds и дополнительные узлы detail.

Перед сохранением существующей карты вызовите read_map и передайте её revision как expectedRevision. Конфликт требует перечитать карту и учесть пользовательские изменения. История ревизий находится в .history. Изменения агента обновляют открытый редактор, если в нём нет несохранённых правок; иначе редактор предлагает перезагрузку и сохраняет локальные правки до решения пользователя. Несохранённые правки не записываются в JSON автоматически.

Пользователь может менять узлы, связи, координаты и поля в инспекторе, импортировать JSON и экспортировать через диалог VS Code. Сохранение проверяет схему, уникальность ID и существование концов связей. Редактирование карты само по себе не исполняет код или SQL.

Сборка включена в npm run compile и npm run package. Отдельно: npm run build:relationship-map. Исходники автономного редактора не включаются в VSIX; включаются готовые dist/relationship-map и исходная карта в resources/relationship-maps.
