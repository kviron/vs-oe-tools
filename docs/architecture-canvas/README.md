# Карта архитектуры расширения

Откройте `index.html` в браузере. Клик по имени метода или файла открывает исходник в VS Code через `vscode://file`. Для корректных ссылок установите в `map.json` поле `sourceRoot` на текущий абсолютный путь репозитория.

`Ctrl + колесо` меняет масштаб вокруг курсора (30–200%). Обычное колесо прокручивает карту. Зажмите среднюю кнопку мыши и двигайте мышь, чтобы перемещаться по карте в любую сторону. Кнопки `−`, `+` и процент в верхней панели тоже управляют масштабом. Узлы можно перетаскивать. `Ctrl+клик` выбирает два узла для новой связи. Щелчок по линии открывает её свойства: можно выбрать другие начальный и конечный узлы, тип связи, подпись или удалить связь. Панель свойств открывается поверх карты при выборе узла или линии и закрывается по клику на пустом месте. Кнопка «+ Условие» создаёт визуальный шаг без исполнения. «Скачать JSON» сохраняет результат, «Открыть JSON» загружает его обратно.

По умолчанию подробные MCP инструменты скрыты, чтобы видеть основные зависимости. Переключатель «Подробные MCP» показывает все узлы. Поиск подсвечивает совпадения; Enter прокручивает карту к первому. Цвет линии означает тип связи. Фиолетовый пунктир и узлы «Предложение» показывают возможное изменение архитектуры, которого пока нет в коде.

Верхняя панель использует иконки. Наведите курсор на кнопку, чтобы увидеть её название. Иконка поиска раскрывает поле, иконка слоёв показывает подробные MCP инструменты.

`Ctrl+Z` отменяет изменения карты; `Ctrl+Shift+Z` или `Ctrl+Y` возвращает отменённое. Перемещение узла считается одним действием, ввод текста в одно поле — одним действием до перехода к другому полю. История хранится в открытой вкладке (до 100 шагов) и не записывается в JSON.

После замены `map.json` скачанной версией обновите локальные данные для открытия HTML без веб-сервера:

```powershell
$json = Get-Content docs/architecture-canvas/map.json -Raw -Encoding UTF8
[System.IO.File]::WriteAllText('docs/architecture-canvas/map-data.js', "window.ARCHITECTURE_MAP = $json;", [System.Text.UTF8Encoding]::new($false))
```

Для обновления списка MCP инструментов из каталогов `src/mcp/tools/*/registration.ts` запустите `node docs/architecture-canvas/sync-tools.cjs`. Для повторного применения проверенных архитектурных узлов и типов связей запустите `node docs/architecture-canvas/enrich-map.cjs`.
