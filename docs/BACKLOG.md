# Бэклог

## Принудительный запуск и восстановление моста VS Code из MCP

Приоритет: высокий. Статус: запланировано. Добавлено: 2026-10-05.

При выполнении задачи 89340 сохранённый адрес моста `vc-ve-tools` перестал
отвечать. Инструменты создания методов и запуска клиентского MCP потребовали
ручного `Developer: Reload Window`. Агент должен иметь отдельный инструмент
восстановления, доступный даже при недоступном мосте.

Требования:

- Добавить независимый MCP-инструмент принудительного запуска/восстановления
  моста для явно указанного workspace и целевого профиля базы.
- Проверять процесс VS Code, активность расширения, актуальность адреса моста
  и готовность обработчика; возвращать этап, результат и причину ошибки.
- Использовать поддерживаемый механизм запуска/активации расширения. Если
  восстановление требует перезагрузки окна с возможной потерей несохранённого
  состояния, сообщать об этом явно и запрашивать подтверждение.
- Не создавать лишние окна VS Code и параллельные мосты; объединять одновременные
  запросы восстановления и ограничивать время ожидания.
- После запуска проверять health/handshake, соответствие workspace и профиля,
  обновлять сохранённый адрес. Открытое окно не считать доказательством готовности.
- Не повторять автоматически мутации с неизвестным результатом: восстановление
  транспорта и повторное выполнение операции должны быть отдельными действиями.
- Не выводить пароли и строки подключения в диагностику.

Критерии приёмки:

- Инструмент доступен при остановленном мосте и восстанавливает его без ручного
  Reload Window там, где поддерживаемые API позволяют это сделать.
- Проверены сценарии: устаревший адрес, остановленный VS Code, неактивное
  расширение, занятый порт, другой workspace и несколько одновременных запросов.
- После восстановления работают чтение объекта и запуск клиентского MCP;
  ранее прерванная мутация не выполняется повторно сама.
- Если восстановление невозможно, результат содержит точную причину и конкретное
  действие пользователя, без ложного сообщения об успешном запуске.
